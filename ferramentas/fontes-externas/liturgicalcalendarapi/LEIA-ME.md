# Dados externos (somente para gerar o índice da Liturgia Diária)

Fonte: projeto **Liturgical Calendar API** — https://github.com/Liturgical-Calendar/LiturgicalCalendarAPI
Licença: Apache 2.0 (ver `LICENSE`). Versão: ver `VERSAO.txt`.

Estes arquivos trazem apenas **referências bíblicas** (em inglês) das leituras
da Missa. Eles são usados uma única vez, pelo script
`ferramentas/gerar_indice_liturgia_diaria.py`, para descobrir qual arquivo do
acervo corresponde a cada dia litúrgico. **O site não depende deles para
funcionar** e nenhum texto litúrgico é copiado daqui.
